# Parking Spot Detection and Classification

  
## Installation

Follow these steps to set up the project on your local machine.

### 1. Clone the Repository
git clone https://github.com/mouhamediheb/PARKING_Spots_detection
cd PARKING_Spots_detection
###2. Create a Virtual Environment
Create a virtual environment to manage dependencies:
**python -m venv .venv**
### 3. Activate the Virtual Environment
**For Windows:**
**.venv\Scripts\activate**


**For macOS/Linux:**
**source .venv/bin/activate**

### 4. Install Dependencies
Install the required dependencies using requirements.txt.

**pip install -r requirements.txt**

### 5. Run the Project
**Make sure you have your video file and mask file ready.**

Then, run the project using:
**python main.py**

### 6. Customize the Mask and Video
**You can change the mask and video_path variables in main.py to use your own files.**


### Usage
Once you run the code, a window will pop up showing the parking spots with their current status (empty or occupied) and a counter at the top-left of the screen displaying the available spots.
You can exit the video stream by pressing the q key.
